# ASESCON

Sistema web interno para la gestión contable y tributaria, consultas SUNAT/SUNAFIL, clientes, comunicaciones y tareas.

## Requisitos

- Docker Desktop con Docker Compose
- Respaldo inicial de las bases `asescon` y `asescon_sunat`

## Ejecución local

Consulta [DOCKER.md](DOCKER.md) para crear la configuración local, importar las bases y levantar el sistema.

La configuración privada, credenciales, documentos tributarios, registros y archivos de trabajo están excluidos del repositorio.
